# Subtraktionskarte

Interaktive React/Vite/Tailwind-Anwendung zur Visualisierung didaktischer Gruppen von Subtraktionsaufgaben bis 20.

## Funktionen

- Tabelle aller nicht-negativen Subtraktionen von `0 − 0` bis `20 − 20`.
- Gleichzeitige Markierung von Ergebnis, didaktischer Gruppe, Untergruppe, Minuend-Zeile und Subtrahend-Spalte.
- Touch- und Tablet-Bedienung über Antippen; Desktop-Bedienung über Hover und Fokus.
- Auf kleinen Bildschirmen bleibt die Karte verschieb- und zoombar, auf mittleren und großen Bildschirmen passt sie sich an die Breite an.

## Entwicklung

```bash
npm install
npm test
npm run dev
```
